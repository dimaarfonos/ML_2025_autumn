

## 1. Сравнение методов градиентного спуска (ГС) и Ньютона

Методы ГС и Ньютона — это итерационные методы минимизации гладких функций, которые строят последовательность точек $x_{k+1} = x_k + \alpha_k d_k$, где $d_k$ — направление поиска, а $\alpha_k$ — длина шага.

### 📝 Отличия, сходства и области применения

| Критерий | Градиентный спуск (ГС) | Метод Ньютона |
| :--- | :--- | :--- |
| **Направление $d_k$** | $d_k = -\nabla f(x_k)$ (антиградиент) | $d_k = -(\nabla^2 f(x_k))^{-1} \nabla f(x_k)$ |
| **Используемая информация** | 1-й порядок (градиент) | 2-й порядок (градиент и гессиан) |
| **Стоимость итерации (Время)** | **Дешево**: $O(n)$ или $O(N_{nz})$ | **Дорого**: $O(n^3)$ (из-за обращения Гессиана) |
| **Скорость сходимости** | **Линейная** (медленная) | **Квадратичная** (очень быстрая) |

#### Преимущества и Недостатки

| Метод | Преимущества | Недостатки |
| :--- | :--- | :--- |
| **ГС** | 1. **Масштабируемость:** Работает при $n \gg 1$. 2. **Дешевизна итерации.** 3. Не требует Гессиана. | 1. **Медленная сходимость** (линейная). 2. Чувствителен к **числу обусловленности** $\kappa$. |
| **Ньютон** | 1. **Крайне быстрая сходимость** (квадратичная). 2. Нечувствителен к $\kappa$. | 1. **Не масштабируется** по $n$ (дорогой $O(n^3)$). 2. Требует вычисления и хранения **Гессиана** ($O(n^2)$). |

#### Когда применять

* **ГС:** Всегда, когда $n$ велико (тысячи и более) или данные разрежены. Это основа для большинства задач в машинного обучения (SGD, Adam).
* **Ньютон:** Когда $n$ мало (сотни) или когда требуется **очень высокая точность** за минимальное число итераций.
* **Практика:** При больших $n$ вместо Ньютона используются его масштабируемые варианты: **Квазиньютоновские методы (L-BFGS)** или **Неточный метод Ньютона (Inexact Newton)**.

## 2. Логистическая регрессия

### 📝 Определение и Задача

**Логистическая регрессия (ЛР)** — это линейный классификатор, используемый для решения задачи **бинарной классификации**.

**Задача:** Оценить вероятность того, что объект $x$ принадлежит положительному классу ($y=1$), с помощью линейной комбинации признаков, пропущенной через сигмоидную функцию:
$$P(y=1 \mid a_i, x) = \sigma(a_i^\top x) = \frac{1}{1 + \exp(-a_i^\top x)}$$
где $\sigma(z)$ — сигмоида.

### 📊 Формулы для $\ell_2$-регуляризованной ЛР

Предполагается, что матрица данных $A \in \mathbb{R}^{m \times n}$ содержит объекты $a_i^\top$ (строки), а метки $b_i \in \{-1, 1\}$. Коэффициент регуляризации $\lambda = 1/m$.

#### 1. Функция потерь (Objective Function $f(x)$)

$f(x)$ является суммой *средней логистической функции потерь* и $\ell_2$-регуляризатора:
$$f(x) = \frac{1}{m} \sum_{i=1}^m \log\left(1 + \exp\left(-b_i a_i^\top x\right)\right) + \frac{\lambda}{2} \|x\|^2$$

#### 2. Градиент ($\nabla f(x)$)

Градиент вычисляется как:
$$\nabla f(x) = \frac{1}{m} A^\top (\mathbf{s} \odot \mathbf{b}) + \lambda x$$
где:
* $\odot$ — поэлементное умножение (операция Адамара).
* $\mathbf{b}$ — вектор меток $(b_1, \dots, b_m)^\top$.
* $\mathbf{z} = - \mathbf{b} \odot (A x)$ (поэлементное произведение $b_i$ на предсказание $A x$).
* $\mathbf{s}$ — вектор, где $s_i = \sigma(z_i) - 1$, то есть $\mathbf{s} = \sigma(- \mathbf{b} \odot (A x)) - \mathbf{1}$.

#### 3. Гессиан ($\nabla^2 f(x)$)

Гессиан является симметричной положительно полуопределенной матрицей:
$$\nabla^2 f(x) = \frac{1}{m} A^\top D A + \lambda I$$
где:
* $I$ — единичная матрица $n \times n$.
* $D$ — диагональная матрица $m \times m$, где диагональные элементы $D_{ii}$ зависят от текущей точки $x$:
$$D_{ii} = \sigma(-b_i a_i^\top x) \cdot (1 - \sigma(-b_i a_i^\top x))$$
* Важно: $0 < D_{ii} \le 1/4$.

## 3. Векторные и матричные операции

Ваши функции `matvec_Ax`, `matvec_ATx`, `matmat_ATsA` используются для эффективной работы с **разреженными матрицами** $A$ и $A^\top$ без явного формирования плотных матриц $A^\top A$ или $A^\top D A$.

| Функция | Математический смысл | Реализация (Пример) |
| :--- | :--- | :--- |
| **`matvec_Ax(A, x)`** | $A x$ (Умножение $A$ на вектор $x$) | `A.dot(x)` |
| **`matvec_ATx(A, y)`** | $A^\top y$ (Умножение $A^\top$ на вектор $y$) | `A.transpose().dot(y)` или `A.T.dot(y)` |
| **`matmat_ATsA(A, D)`** | $A^\top D A$ (Центральная часть Гессиана) | `A.T.dot(D).dot(A)` (Для разреженных $A$) |

### Реализация Градиента и Гессиана ЛР

В вашем файле `oracles.py` вы реализовали градиент и гессиан ЛР, используя эти операции для поддержки разреженной матрицы $A$ (`scipy.sparse.csr_matrix`):

#### 1. Вычисление Градиента

1.  Вычисляется предсказание (score) $s = A x$ (`matvec_Ax`).
2.  Вычисляется вектор $\mathbf{z} = -\mathbf{b} \odot s$.
3.  Вычисляется вектор ошибок $\mathbf{s} = \sigma(\mathbf{z}) - 1$.
4.  Градиент: $\nabla f(x) = \frac{1}{m} A^\top (\mathbf{s} \odot \mathbf{b}) + \lambda x$. Используется `matvec_ATx` для $A^\top (\dots)$.

#### 2. Вычисление Гессиана

1.  Вычисляется диагональная матрица $D$ с элементами $D_{ii} = \sigma(\mathbf{z}_i) (1 - \sigma(\mathbf{z}_i))$.
2.  Гессиан: $\nabla^2 f(x) = \frac{1}{m} A^\top D A + \lambda I$.
    * $A^\top D A$ вычисляется с помощью `matmat_ATsA` (или последовательностью `A.T.dot(D.dot(A))` с использованием разреженных форматов).
    * $D$ — разреженная диагональная матрица, а $A$ — разреженная, но $\mathbf{A}^\top \mathbf{D} \mathbf{A}$ **в итоге будет плотной** матрицей $n \times n$ (если $n$ большое, это причина, по которой метод Ньютона замедляется).

## 4. Линейный поиск

**Линейный поиск** (Line Search) — это процедура, используемая на каждой итерации метода спуска для выбора оптимальной **длины шага $\alpha_k$** в заданном направлении $d_k$. Цель — найти $\alpha_k$, которое максимально уменьшит значение функции $f(x_{k+1}) = f(x_k + \alpha_k d_k)$ при сохранении стабильности алгоритма.

### 🔑 Стратегии выбора шага

| Стратегия | Описание | Применение |
| :--- | :--- | :--- |
| **Точный поиск** | Решает одномерную задачу $\min_{\alpha_k > 0} f(x_k + \alpha_k d_k)$. | Возможно только для простейших функций (например, квадратичных). |
| **Поиск по Армихо (Armijo Rule)** | Выбирает $\alpha_k$ так, чтобы было достаточное уменьшение функции. $$f(x_k + \alpha_k d_k) \le f(x_k) + c_1 \alpha_k \nabla f(x_k)^\top d_k$$ ($c_1$ — малая константа). | Гарантирует сходимость для выпуклых функций. |
| **Поиск по Вульфу (Wolfe Conditions)** | Сочетает условие Армихо (достаточное уменьшение функции) с **условием кривизны** (исключает слишком малые шаги). $$\nabla f(x_k + \alpha_k d_k)^\top d_k \ge c_2 \nabla f(x_k)^\top d_k$$ ($c_2 > c_1$). | Стандартный выбор для большинства методов спуска, включая ГС и Ньютона, обеспечивает высокую скорость сходимости. |
| **Постоянный шаг** | $\alpha_k = c$ (фиксированная константа). | Применяется в SGD или когда константа Липшица градиента $L$ известна ($\alpha \le 1/L$). |

## 5. Матричные свойства и разложение

### ➕ Положительная определённость матрицы

Квадратная симметричная матрица $A \in \mathbb{R}^{n \times n}$ называется **положительно определённой** (positive definite, $A \succ 0$), если для любого ненулевого вектора $z \in \mathbb{R}^n$:

$$\mathbf{z}^\top A \mathbf{z} > 0$$

* **Значение:** Положительная определённость Гессиана $\nabla^2 f(x)$ гарантирует, что функция $f(x)$ **строго выпукла** в окрестности $x$, а направление Ньютона $d_k$ является направлением спуска.
* **Свойство:** У положительно определённой матрицы **все собственные значения строго положительны**.

### 📐 Разложение Холецкого

**Разложение Холецкого** (Cholesky Decomposition) — это метод факторизации матрицы $A$, который представляет её в виде произведения нижнетреугольной матрицы $L$ и её транспонированной верхней треугольной матрицы $L^\top$:

$$A = L L^\top$$

#### Для каких матриц работает?

Разложение Холецкого применимо **только** к **симметричным положительно определённым** матрицам.

#### Когда применяется?

Основное применение — **эффективное решение систем линейных уравнений** вида $A x = b$, где $A \succ 0$:

1.  Сначала решается нижнетреугольная система $L y = b$ (прямая подстановка).
2.  Затем решается верхнетреугольная система $L^\top x = y$ (обратная подстановка).

В методе Ньютона для решения системы $\nabla^2 f(x) d_k = -\nabla f(x)$:
1.  Вычисляется разложение Холецкого $L L^\top = \nabla^2 f(x)$.
2.  Находится направление $d_k$ через прямую и обратную подстановки.

Это позволяет найти $d_k$ за $O(n^3)$ (стоимость факторизации) + $O(n^2)$ (стоимость подстановок), что значительно быстрее, чем прямое вычисление $A^{-1}$ ($O(n^3)$ с более высокой константой).
